## Candidate

Only the FP16 medium-k class, inner=512 and k<=12, takes the new path.
The enclosing dispatch restricts this class to 9<=k<=16. This includes
padded E=481..511, tested explicitly at E=497. k>=13 keeps its old path.

Sixteen Sort32 chunks retain 12 pairs each, giving 192 pairs per row.
Four 4-way merges each produce 48 pairs. Retain 12 from each group,
then merge those four contiguous lists into 48 final pairs. Gather uses
the resulting 96-float row stride. Copy block lengths are 3 * 32 bytes.
All copied regions are fully initialized; no prefix-padding Duplicate
is needed for this 16-chunk layout. Existing UB allocation and batch
capacity are retained, including the Sort32 repeat cap of 255.

MrgSort uses equal contiguous lists, validBit=15 and suspension=false.
At batchRows=15, first-stage repeatTimes is 60, final-stage 15.
API constraints were checked against the installed CANN 9.0 headers
and Huawei's MrgSort documentation:
https://www.hiascend.com/doc_center/source/zh/canncommercial/80RC3/apiref/ascendcopapi/atlasascendc_api_07_0222.html
