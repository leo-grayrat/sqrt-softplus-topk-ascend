Static formulas for the FIRST SetInput final length argument:
Let R=repeatTimes, B=src0BlockStride, S=src0RepeatStride.
Counter, assuming runtime GetMaskLow returns requested mask m:
  length = 4 * (32*((R-1)*S + (m-1)*B) + 4*m).
  With R=1, B=1, m=n: length = 144*n - 128 bytes.
  n=3072: 442240 bytes versus logical src0 length 12288 bytes.
  n=10240: 1474432 bytes versus logical src0 length 40960 bytes.
Normal:
  length = 4 * (32*((R-1)*S + 63*B) + 256).
  With R=n/64, B=1, S=8: length = 16*n + 8064 bytes.
  n=3072: 57216 bytes versus logical src0 length 12288 bytes.
  n=10240: 171904 bytes versus logical src0 length 40960 bytes.
Thus Normal statically reduces this argument substantially but does not make it equal to the logical input byte count.
