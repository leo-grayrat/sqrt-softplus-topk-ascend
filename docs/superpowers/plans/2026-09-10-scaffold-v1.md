# Scaffold V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立一个最小但可验证的比赛仓库骨架，先固定 PyTorch 正确性参考和测试，再等待真实 CANNJudge starter project。

**Architecture:** `reference/reference.py` 区分官网示例计算、Top-K 前移的数学等价实现，以及题面声明的输出 dtype；`tests/test_reference.py` 验证这些关系。`submission/` 暂不放 Ascend C 代码，只说明等待真实 starter project。

**Tech Stack:** Python 3, PyTorch, pytest, Git/GitHub

**Spec:** `docs/superpowers/specs/2026-09-10-sqrt-softplus-topk-design.md`

## Global Constraints

- 不猜 CANN/Ascend C API。
- 不自行创造比赛工程结构。
- 官网 PyTorch 示例是计算基准；题面另声明输出 dtype 与输入一致，两者的矛盾必须显式记录。
- 不把本地测试或编译通过描述成 Judge AC 或性能提升。
